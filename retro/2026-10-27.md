**Evidence**

**Edit 3 — `CLAUDE.md` (working agreement):** one line — *"Scored artifacts are committed (never git-ignored) at fixed paths: `.claude/prompts.jsonl`, `evals/<name>/results.json`; each line of the prompt log has a `timestamp`."*

## Cause D — Auto-commit-push loses traceability and fires for ANY repo session
**Evidence**
- `git log` is dominated by generic `chore: factory-loop auto-commit <iso>` messages — ticket intent is lost except where a manual commit preceded the stop.
- Today the two nested `claude -p` audit sessions each triggered the Stop hook and **auto-pushed to `main`** (`ede109f`, `518d21a`) with no human in the loop.

**Edit 4 — `SKILL.md` (Commit & push):** one line — *"For ticket work, make a real commit with a meaningful message before stopping; the auto-commit Stop hook is only a backstop, and it (and any headless/nested session in this repo) will push to `main`."*

## Cause E — Repeated human re-authorization of merges (review-gate friction)
**Evidence**
- Humans had to say *"Merge PR#6 yourself"*, *"ticket #6 approved"*; the auto-mode classifier blocked self-merge until explicit authorization (correct, but round-trippy).

**Edit 5 — `SKILL.md` (Build workflow, PR handoff):** tighten the hand-off line so the loop's PR comment tells the human the **exact one-liner** to merge (`gh pr merge <n> --squash`) — reduces back-and-forth.

## Cause F — Environment gotchas caused rework
**Evidence**
- `gh … --body '…'` broke on an apostrophe → switched to `--body-file`.
- Git Bash mangled `git show origin/main:path` (colon) → needed `MSYS_NO_PATHCONV=1`.
- Playwright blocks `file://` → had to serve the app over local http.
- First `git push` hung on the `manager` credential helper → fixed once with `gh auth setup-git`.
- The EMU GitHub account (403) couldn't write to the external repo → needed a personal account.

**Edit 6 — `SKILL.md` (Preflight):** one line of gotchas — *"Post comments with `--body-file`; browser-verify over local http (not `file://`); run `gh auth setup-git` once; use a non-EMU account for external repos."*
